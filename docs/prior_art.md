# Prior-art boundary

Last checked: 2026-07-17.

The components of this program are not individually new. The research gap is
their composition:

> selected-site OSS intervention profiles + output-only controlled projections +
> leave-dependency-cluster-out transfer + prospective failure prediction +
> explicit abstention bookkeeping + later open-set validation and probability
> calibration.

The current OSS-1 object is specifically a five-surface design freeze: exact
task generator, intervention table, dependency-cluster split, independent unit,
and blind evaluation interface, with prospective scoring nested inside the
blind surface. Execution is a separate two-stage chain from discovery
authorization, through a count- and evidence-closed site report, to a final
output-independent lock with `authority_commitments=null`. Both templates are
unassigned; the private post-output sealed-evaluation authorization template is
also unassigned, and no model or API call has occurred.

The current blind-evaluation contribution is a measurement contract rather
than a claim of novel cryptography or isolation. After the exact raw-output
inventory and ledger declare the 16,416 pre-auditor causal-label, behavior-fit,
and sealed-test forwards complete under the authority, with diagnostics
pending, three private post-output fold authorizations bind the raw 2,880 weak
and 1,152 challenge trials, output-derived keys, and HMAC-opaque auditor
surfaces. Three declared isolated workers must commit before any reveal; the
fold-run records contain no reveal bytes or nonces. The coordinator first
validates every artifact, redaction surface, and common root, then invokes the
exact four-field opening provider and validates the other-two-fold development
material under fold-private cluster-ID rekeying before applying one equal-three-
cluster global gate. A one-fold score is
non-authoritative. Capability IDs are declarations rather than physical
attestation, and fold-local estimator training/replay remains a residual P1;
without separate closure the assurance is prediction locking.

## Directly adjacent output-only work

[Distribution-based perturbation analysis](https://proceedings.mlr.press/v267/rauba25a.html)
tests whether stochastic text-output distributions change under arbitrary input
or model interventions. It provides model-agnostic p-values, controlled error
rates, and effect sizes. It does not infer an interventionally defined latent
computation class.

[Distribution-based sensitivity analysis](https://arxiv.org/abs/2512.11573)
estimates black-box token importance without gradients or logits. It is input
attribution, not process identification.

[LLMmap](https://www.usenix.org/conference/usenixsecurity25/presentation/pasquini)
uses active queries and generated text to identify 42 LLM versions with more
than 95 percent accuracy using as few as eight interactions. This establishes a
serious confound: an output classifier can learn model identity while appearing
to learn mechanism.

OSS-1 addresses that confound structurally at the pilot tier: each of exactly
three dependency clusters contains one semantic, one surface-cue, and one mixed
anchor under the same within-cluster architecture family and tokenizer. Thus
all nine units form three complete anchor blocks, and cluster or architecture
identity cannot directly determine the label.

[Fingerprinting Inference Systems of Large Language Models](https://arxiv.org/abs/2605.29979)
reports that numerical differences from inference engines, attention backends,
and hardware can propagate to observable text and support component
identification. Runtime identity therefore needs its own control surface.

[AuditBench](https://arxiv.org/abs/2602.22755) provides 56 models with 14
implanted hidden behaviors and reports that diverse-prompt black-box tools are
especially effective in its investigator-agent setting. Hidden-behavior
discovery is adjacent to, but different from, a causal computation-class
estimator.

[Constitutional Black-Box Monitoring for Scheming in LLM Agents](https://arxiv.org/abs/2603.00829)
trains prompted monitors on synthetic trajectories and evaluates on held-out
agent trajectories. It is behavior monitoring rather than latent mechanism
identification.

## The OSS calibration side

[MIB: A Mechanistic Interpretability Benchmark](https://proceedings.mlr.press/v267/mueller25a.html)
evaluates circuit and causal-variable localization over multiple tasks and
models. Its causal-variable track is a natural source of reference tasks and
evaluation discipline.

[Inducing Causal Structure for Interpretable Neural Networks](https://proceedings.mlr.press/v162/geiger22a.html)
develops causal abstraction through interchange interventions. This project
uses interchange-intervention accuracy as one ingredient of an operational
reference profile, not as an infallible ground truth.

[Internal Causal Mechanisms Robustly Predict Language Model Out-of-Distribution Behaviors](https://proceedings.mlr.press/v267/huang25af.html)
shows that causally relevant internal variables can predict OOD model behavior
better than causal-agnostic features. Latent Trace Tomography asks whether a
carefully designed external response surface can estimate enough of that causal
profile to retain prospective power.

## Behavioral latent-variable models

[Reasoning aligns language models to human cognition](https://arxiv.org/abs/2602.08693)
fits a task-specific mechanistic behavioral model with latent variables for
memory, strategy, choice bias, and occlusion awareness. It demonstrates that
low-dimensional latent process models can explain behavior, while also
illustrating why construct validity is task-specific and should not be
generalized casually.

## Limits that shape this repository

[Everything, Everywhere, All at Once: Is Mechanistic Interpretability Identifiable?](https://arxiv.org/abs/2502.20914)
asks whether mechanistic explanations are unique. Output-only observation makes
the ambiguity at least as severe.

[The Limits of Predicting Agents from Behaviour](https://arxiv.org/abs/2506.02923)
analyzes limits on inferring or predicting agents from behavior. The practical
response here is probe-relative equivalence classes and abstention. OSS-1 does
not freeze an unknown-regime generator, selective-risk formula, or open-set
gate; those require a fresh successor contract.

The tomography analogy is therefore qualified. Unlike X-ray CT, the forward
operator is unknown, nonlinear, and potentially nonstationary; changing a
prompt may change the object being measured. “Tomography-inspired system
identification” is safer than claiming a Radon-style reconstruction.

## Claims to avoid

- first black-box LLM interpretability or auditing method
- first proprietary-model causal analysis
- first output-only model or runtime fingerprint
- recovery of true hidden chain of thought
- exact internal trace reconstruction
- mechanistic interpretability without internals, stated without qualification

The defensible target is:

> an OSS-calibrated, output-only estimator of selected-site intervention-
> susceptibility equivalence classes, with held-out learned-state dependency-cluster transfer,
> prospective prediction, and explicit abstention bookkeeping. Open-set
> validation and probability calibration remain separately gated successors.

## Citation corrections preserved during bootstrap

Two nearby arXiv identifiers are easy to conflate:

- arXiv:2512.11573 is “Visualizing token importance for black-box language
  models.” The inference-engine/hardware paper is arXiv:2605.29979.
- arXiv:2603.00829 is “Constitutional Black-Box Monitoring for Scheming in LLM
  Agents.” AuditBench is arXiv:2602.22755.

These corrected mappings are used throughout this repository.
