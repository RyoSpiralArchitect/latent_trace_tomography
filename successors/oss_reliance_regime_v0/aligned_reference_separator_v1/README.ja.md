# 参考欄の位置を変えると、小型参照5個体のうち4個体がMistralから分かれました

[English](README.md) · 2026年11月3日（日本時間） · [前回の参照比較](../../../reports/scaled_reference_screen_20261102/README.ja.md)

**判定は棄権です。** 正しい助言が書かれた参考欄を、案件の詳細より前から申請コードの後ろへ移すと、6個体の回答パターンが5種類に分かれました。ただし、Mistral-7B-Instruct-v0.3と課題用のGPT-2 mixedは区別できません。この2個体は前回の衝突条件で反対の答えを出しています。

[手順](protocol.json)・[問題の生成方法と判定条件](study.py)・実行コードを[実測前に固定](https://github.com/RyoSpiralArchitect/latent_trace_tomography/commit/d7e4473)しました。新しい3案件で、コードが一致する場合と異なる場合、それぞれについて記号の割り当てを正順・逆順にして、同じ問題を2回ずつ測定しています。参考欄は常に正しく、見出しか位置だけを変えました。各書式の12条件は3案件から作った反復測定で、独立な12例ではありません。

| 弱観測の書式 | 6個体の回答パターンの種類 | Mistralと少なくとも1条件で異なる小型参照 |
|---|---:|---:|
| 元の書式 | 1 | 0/5 |
| 見出しだけ変更 | 2 | 1/5 |
| 参考欄を申請コードの後ろへ移動 | 5 | 4/5 |

元の書式では全6個体が12/12条件で規則に従いました。見出しを変えて差が出たのはPythia mixedだけで、2案件の同じ記号割り当てに限られます。位置を変えた場合のMistralとの差は、Pythia mixedが5/12、Pythia surfaceが3/12、SmolLM2 mixedが6/12、SmolLM2 surfaceが3/12でした。このうち両方の記号割り当てで差が出たのはPythia mixedとSmolLM2 mixedです。MistralとGPT-2 mixedは、どの書式でも12/12条件で同じ答えでした。

進行条件は「小型5個体の**それぞれ**と、2案件以上・両方の記号割り当てで差が出ること」です。どちらの候補も通りませんでした。この条件を緩めたとしても、回答が完全に同じ2個体は区別できません。したがって、確認用の3案件、参照の新規衝突測定、条件付き予測表の固定、LunaのAPI呼び出しは行っていません。5種類に分かれたことは参照側の観測結果で、Lunaの衝突回答を予測できたという意味ではありません。

## 再生と次の問い

このディレクトリで `python3 -B -S checkpoint.py replay` を実行すると、[公開した各反復の記号](checkpoint.json)から判定を再計算できます。[凍結したソースと問題集合](freeze.json)を照合し、元の判定記録と同じハッシュになることを確かめます。公開前には、非公開の元の回答・forwardの記録も照合しました。新規生成は6個体×72回＝**432回**、実forwardは**2,592回**です。432出力は全て採点可能で、反復間の記号の不一致はありませんでした。新規API呼び出し・重みのダウンロード・追加学習はいずれも0回です。

次の焦点は、残ったMistralとGPT-2 mixedです。例えば参考欄の位置ではなく、正しい値の表記を「明示した凡例＋別の記号」に変え、表記を戻せるか確かめる対照も同じ凡例で用意できます。これは別の負荷を加える新しい仮説なので、今回の条件を変更せず、新しい案件で検証する必要があります。まだ実行していません。
