# Public data key / 公開データの読み方

All measurements predate this publication. These are synthetic filing texts and observed model responses, not generated fixtures. The public export uses an explicit list of fields, never a copy of a raw API or GPU log. / すべて保存済みの実測です。運用ログではなく、合成問題と実際の応答から選んだ項目のみを配布します。

| File | One JSON line / 1行の内容 |
|---|---|
| `data/prompts.jsonl` | `[cell, exact_user_text]`. 192 open-weight texts (including mirrored donor filings); 48 aligned API texts. GPT-2 studies share a text only if the retained prompt hashes agree. |
| `data/trials.jsonl` | `[study, checkpoint, cell, arm, visible_response, physical_forwards]`. 960 `cue` + 2,688 `joint`. Answers are exact strings, including leading whitespace. |
| `data/luna.jsonl` | `[cell, repeat, visible_response]`. Two separately dispatched responses for each aligned text; no flipped-sibling outcomes. |

**Cells.** Reference: `panel/docket/required/candidate/map/advisory`. X and Y name distinct codes **within** a docket; X/X and Y/Y are matches. Only X-required recipients are patched; the other clean filings supply donors. `original` uses the historical six dockets, `balanced` the new six. API: `luna/docket/written-decision/map/presentation`. `identity` means PASS→A; `swap` means PASS→B. The replay reads both map lines and the actual code values. A decision must match the entire trimmed response: A, B, FINAL: A, or FINAL: B. Nothing is repaired.

**Arms.** `base` is a clean generation. `cue6:T` is a targeted cue patch at zero-based layer 6; `cue3` and `map3` are other sites in the first experiment. S = self, T = natural donor, N = signed-permutation norm-matched null. In the second experiment, `T:context:N` means target the advisory and use the CONTEXT donor's null at the final candidate token. `T:none:S` is a cue-only target with an explicit candidate self replacement. RELAY is never the primary arm. See the exact [cue](data/cue_protocol.json) and [joint](data/joint_protocol.json) protocols for design, donor selection and the prefill-only hook boundary.

**Cue readout.** For both prespecified layers in the first assay, `all_changes` compares edited vs. natural recipient; `toward_donor_advice` additionally requires the new answer to agree with the donor's *written advice*. `to_donor_on_informative` instead requires different natural recipient/donor decisions and the edited answer to match the donor's *natural output*. `conditional_donor_rate` divides this last count by `informative_pairs`, returning JSON `null` when it is zero. These are not interchangeable, even for a binary task. The replay validates the entire fixed wording (including the law) and the 48 distinct endpoint user texts, presentation lines and their matched codes.

**Contrasts.** For a fixed donor route, use two letters in cue/candidate order; each entry counts mapped PASS over the same 12 recipients (six dockets × two maps). The candidate increment is TT−TS; the interaction relative to self replacements is TT−TS−ST+SS; the interaction relative to the two site-specific nulls is TT−TN−NT+NN; the direct candidate specificity contrast is TT−TN. Preserve both within-cell switch directions; a sum of zero need not imply no switches. The two fresh CONTEXT strata are the only primary gates. See [English](README.md) / [日本語](README.ja.md) for direction and scope.

**Evidence levels.** The symbol ledger permits independent response recounts for the two interventions and the aligned Luna experiment. The preceding coded-advisory, archived-text reference screen and cross-map replication are published at **summary level** in `context.json`; these should not be described as row-level replays. The CPU tensor reconstructions were performed locally: the public file carries their receipt fingerprints, not the vectors. Acquisition columns such as physical forwards are reported counters, not an independent GPU observation. No private API key, request identifier, response identifier, hardware inventory, raw runtime log or checkpoint is needed for the public replay.

**Maintainers with the original private evidence** can regenerate the projection without sending anything. From this directory run `python3 -B -S export_public.py /path/to/retained-study-root` to compare bytes with the checked-in data. An optional `--out NEW_DIRECTORY` creates a separate projection and refuses an existing destination. Everyone else can run `replay.py` without those sources. `manifest.json` binds the published files; the Git commit supplies the external version pin.
